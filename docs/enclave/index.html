Enclave - Client project · Web SaaS(02)
01

Overview

A UI/UX design project focused on creating a clean, modern and intuitive digital platform. I designed the interface in Figma, working on user flows, responsive layouts, navigation and reusable components.

02

My approach

I wanted Enclave to feel calm and orderly, even with many products, organizations and license requests to manage. I kept the interface neutral, let status labels carry the meaning, and kept the most frequent actions close at hand.

03

Challenge / Goal

The goal was to organize the platform so people can find what they need quickly on any screen size with navigation that stays predictable and components that look and behave the same across every page.

04

Structure

The work was organized in four layers, each building on the previous one: from the paths people take, to the components that make every screen consistent.

01

User flows

Mapping the main paths through the platform before designing any screens.

02

Navigation

A consistent navigation pattern that works on desktop and adapts on smaller screens.

03

Layouts

A shared grid and spacing system used across all pages and breakpoints.

04

Components

Reusable components built with Auto Layout and variants.

05

Key Screens

The main screens of the platform, designed on a shared grid with consistent navigation and reusable components.

01License Requests

02Products

03Organization

06

Responsive Design

The layout adapts to the space available: the sidebar navigation collapses into a compact icon rail, giving tables and dashboards more room while the content hierarchy stays the same.

07

Key decisions

The choices that shaped the final interface.

01

Status at a glance

Licenses and requests use consistent status labels — such as Active, Pending or Revoked — so their state can be read without opening each item.

02

Focused actions in dialogs

Granting a license or reviewing a request happens in a compact dialog over the current page, so the context is never lost.

03

A dashboard that points to what’s next

The dashboard pairs overview cards with recent requests and quick actions, so it works as a starting point, not just a report.

08

Final UI

A calm, neutral interface where typography and spacing do most of the work, keeping the focus on content and the most important actions.
